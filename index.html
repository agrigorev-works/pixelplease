FAQ

What is the fastest way to create a custom pixel font?

pixelplease is a browser-based pixel font generator for graphic designers, interface designers, and type experimenters. It turns a regular typeface into a usable pixel-style TTF, not just a raster image effect. Start from a bundled Google font or upload your own TTF/OTF font, tune the effect, and download your pixel font package.

Are my uploaded fonts and data private?

Yes. pixelplease is a local browser tool: no registration, login, or account is needed. When you upload a TTF or OTF, the file is read inside your browser for that session. pixelplease does not upload it, store it on a server, or send the font, sample text, or generated TTF data to analytics. The tool only applies the pixel effect locally and lets you download your pixel font.

How do I turn a regular font into a pixel font?

Pick a starting font, then adjust the grid, threshold, expand, and shift controls until the pixel look is right. pixelplease re-renders each glyph onto a pixel grid, so you can quickly convert an existing typeface into a full pixel-style font directly in the browser.

Can I start from a Google font?

Yes. pixelplease ships with bundled demo Google fonts so you can create a pixel-style font without uploading anything first. These demo fonts include their OFL license files for testing the pixel effect.

Can I upload my own TTF or OTF font?

Yes. You can upload a TTF or OTF font and pixelize it with the same controls as the bundled fonts. Your uploaded font stays on your machine, and you remain responsible for its license.

How do I download and install the pixel font?

When the effect looks right, download the ZIP package. It contains the generated TTF and NOTICE.txt; bundled demo-font downloads also include source license files. Each generated TTF is named with PixelPlease, a compact source code, pixel recipe, short hash, and style, so different pixel fonts can be installed side by side instead of overwriting each other. Install the .ttf like any other font and use it in design tools, interface mockups, posters, or anywhere TTF fonts are accepted. The downloaded font is meant for testing and practical use, not full professional type production.

What do the grid, threshold, expand, and shift controls do?

The grid sets the pixel resolution, and the threshold decides which parts of each glyph become solid pixels. Expand and shift fine-tune weight and alignment so letters stay readable on the grid.

Does pixelplease work with any font?

pixelplease works with most standard TTF and OTF fonts, and clean geometric typefaces usually pixelize best. Very thin, decorative, or script fonts can lose detail on a low-resolution grid. It is a pixel font maker, not a complete font-production tool, and it does not guarantee every glyph or language.

Can I use the generated pixel font commercially?

That depends on the license of the source font, not on pixelplease. Pixelizing a font does not grant new rights, and the original license still controls how you may use the output. Always check the source font terms before using a generated pixel font commercially.

What does the OFL / SIL Open Font License mean here?

The bundled demo fonts are provided under the SIL Open Font License, a permissive license that allows use, modification, and redistribution. OFL fonts still require copyright and license notices to stay with the font. For any font you upload, its own license applies.
