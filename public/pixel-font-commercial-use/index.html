Can I use a generated pixel font commercially?

Commercial use depends on the source font’s license. Pixelizing a font creates a derivative; it does not remove the original restrictions. The license for pixelplease’s application code is separate from the license for any font you generate.

Ask three separate licensing questions

  1. Use: may you use the font in the client work, product or artwork you are making?
  2. Modify: may you change its glyph shapes and create a derivative font?
  3. Distribute or embed: may you send that derivative to someone else, ship it in a game, or serve it from a website?

A desktop license that permits designing a poster does not automatically permit modifying or distributing the font software. “Free download” is not the same as permission for all three activities. Keep the source license and its version with your project.

What bundled OFL fonts allow

The bundled demo fonts use the SIL Open Font License. It permits commercial use, modification and redistribution subject to its conditions. The OFL FAQ distinguishes a design made using a font from distribution of the font software itself: your poster or game does not become OFL-licensed simply because it uses the font.

When distributing an OFL derivative, retain the original copyright and license notices, keep the font under the OFL, and respect any Reserved Font Names unless you have the required permission. OFL fonts cannot be sold by themselves; including them in a larger permitted software package is different. Check SIL’s modification guidance for the release requirements.

What the export package does—and does not—settle

pixelplease uses generated family names beginning with PixelPlease and includes NOTICE.txt. Bundled exports also include source license material. Keep it with the font when sharing. Those packaging steps help preserve provenance; they do not verify an uploaded font’s terms on your behalf.

The exported character set is Basic Latin, and the result is a modified font, not an official edition of the original family. Do not market it as if the original designer endorsed your derivative. If a source license is unclear, use a clearly licensed alternative or ask its rightsholder.

Check the specific handoff

  • Client artwork: distinguish the finished image from delivery of the editable font.
  • Website: verify that serving the font file to visitors is permitted.
  • Game: check distribution and required license files alongside the game package.
  • Figma: verify rights before sharing the TTF or uploading it to a cloud account.

Continue with the website setup or game-font checklist once the rights are clear. For unusual licensing terms, the original license and rightsholder—not this general guide—are the authority.
