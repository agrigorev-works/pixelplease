How to make a pixel font

pixelplease turns an existing source font into a downloadable generated pixel-style TTF directly in your browser. Start from a bundled Google Font or upload a licensed TTF/OTF, tune the pixel effect, and export a package you can install like a regular font.

1. Choose a source font

Start with a bundled permissive Google Font or upload a local TTF/OTF file that you have the right to modify. Uploaded fonts stay in your browser for the current session and are not sent to a server.

2. Tune the pixel effect

  1. Adjust grid density to control how coarse the generated pixel style feels.
  2. Use threshold and expand to balance weight and readability.
  3. Shift the sampling grid when strokes need a cleaner alignment.
  4. Switch between pixels, dots, vertical lines, and horizontal lines.

3. Export the generated TTF

When the preview works, download the ZIP package. It includes a generated TTF plus notice files. Bundled demo-font exports also include source license files.
