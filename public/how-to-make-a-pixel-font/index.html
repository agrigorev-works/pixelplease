How do I make a pixel font?

To make a pixel font without drawing every letter, start with an existing font, sample its shapes onto a grid, and export the result as a new font. pixelplease is a free online pixel font generator with a live preview and a downloadable TTF package; no signup is required.

1. Choose a source for your custom pixel font

Open the generator and start with a bundled font. Merriweather is the default; Inter or Lato can be useful comparisons when you want simpler strokes. If you already have a typeface, choose Upload font and use a licensed TTF or OTF. Check the modification rights before turning a commercial font into a derivative.

Decide whether you are making a poster title, a game label or a small interface caption. Test the actual words and size you need. A dramatic headline can tolerate details that disappear in a tiny score display. If you want to draw a completely new alphabet one pixel at a time, use a glyph editor instead: this font maker transforms existing letters rather than providing a blank drawing grid.

2. Tune the grid, then the weight

Choose the pixels effect first, so you can judge the letter structure before trying dots or lines. Change one control at a time:

  • Pixels-per-em: lower values make a coarser grid; higher values retain more detail.
  • Threshold: a higher threshold requires more coverage to fill a cell, so thin strokes may disappear.
  • Expand: grows occupied cells to add weight; too much can close the holes in letters.
  • Shift X/Y: moves the sampling grid relative to the source shape, which can recover a stroke that lands between cells.

The effective grid is aligned to the source font’s units, so nearby density settings can sometimes produce the same result. Use the preview rather than assuming every slider step changes a cell.

3. Check more than one attractive word

Try Hamburgefonts 0123456789 Il1 O0 rn m, then your real headline. Look for closed counters in a, e and 8, missing punctuation, or pairs that become indistinguishable. Compare at the intended display size, not only a large zoom.

The current export covers Basic Latin (U+0020–U+007E) only. It does not preserve a source font’s entire language coverage, kerning or ligatures. If text looks soft rather than structurally broken, use the blurry pixel font checklist.

4. Download and test the actual font

Choose Download font. Unzip the package and keep the generated TTF, NOTICE.txt and any bundled license files together. Then install the font and test it in your destination app. The generated family name starts with PixelPlease, not the original family name.

Uploaded font files are processed locally; there is no account or server upload step. Download the result before leaving the session. This is an editable-text font workflow, not a PNG text effect or a complete type-design editor.
