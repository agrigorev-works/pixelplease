How do I convert a TTF or OTF to a pixel font?

Upload a TTF or OTF that you are allowed to modify, choose a pixel grid, and download the generated TTF inside a ZIP. This changes the letter shapes: it is not just renaming a font file or converting one container format into another.

Upload a TTF or OTF, not a webfont or image

Extract the font from its ZIP first. In pixelplease, choose Upload font and select the actual .ttf or .otf file. A Google Fonts CSS URL, a WOFF2 webfont, a PDF and a screenshot are not interchangeable inputs.

Use a static font style where possible. Variable-font axes and advanced font features are not preserved by this workflow. A valid extension also does not guarantee that every font’s internal format can be parsed. If a file fails, try a known bundled font to separate a file-compatibility issue from a browser problem.

TTF to pixel font vs TTF to bitmap font

The tool reads glyph shapes, samples them on a grid, and builds a new outline font from the occupied cells. The OpenType specification distinguishes glyph descriptions from the layout data that positions text; a visual transformation does not automatically carry across every layout feature.

Start with pixels, adjust pixels-per-em, then tune threshold, expand and shift. The step-by-step creation guide explains each control. Dots and line effects are alternatives after the basic letters are readable.

If you searched for a TTF-to-bitmap-font converter because your engine requires a PNG atlas and character mapping, this export is not that asset. Pixelplease returns outlines with a pixel-style appearance; choose an atlas exporter when your renderer specifically needs bitmap images.

Know what the output keeps and loses

The output is a generated font labelled as TTF in a ZIP package, with its own PixelPlease family name. Current generation covers Basic Latin, U+0020–U+007E. Do not assume that Cyrillic, accented letters, emoji, ligatures, kerning, hinting or a variable weight axis survive because they existed in the source.

For example, a sample containing Hello 123! fits the supported range; café includes a character outside it. Check your actual content before using the result in a multilingual interface. A fallback may hide missing glyphs by silently switching fonts.

Export, install, and keep the license

Download the package, extract it, then install the generated file. Keep NOTICE.txt and the source license with any permitted redistribution. Bundled demo exports include their OFL material; an uploaded font still needs its own license check.

Pixelization does not make a restricted font unrestricted. Read the commercial-use guide if the result will go to a client, website or game. The app processes the upload in your browser and does not send your font to a server.
