pixelplease

Convert TTF to pixel font

pixelplease is a free browser tool for turning a TTF, OTF, or bundled Google Font into a generated pixel-style TTF package. It is built for quick visual experiments, interface mockups, posters, and prototype typography.

Local browser conversion

Font parsing and generated font creation happen in the browser. The uploaded source font, edited sample text, and generated TTF data are not uploaded to a server.

What the export includes

  • A generated pixel-style TTF package.
  • A notice file describing the source and generation context.
  • Bundled source license files when the export starts from a bundled demo font.

License reminder

A generated pixel font is still derived from its source font. The original source font license controls whether you may modify, redistribute, or use the output commercially.
