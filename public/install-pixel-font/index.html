How do I download and install a pixel font?

Download the ZIP from pixelplease, extract it, and install the generated .ttf file—not the ZIP itself. Then reopen the app where you want to type and look for the generated family name beginning with PixelPlease.

Download the full package first

Wait until the output is ready, then choose Download font. The ZIP includes the generated TTF and NOTICE.txt. Exports from bundled demo fonts also carry source OFL license material. Keep those files together even if your operating system only needs the TTF to install.

The file and family names include source/effect information and a short hash so variations can coexist. Do not search only for the original name, such as Inter, after installing a generated version.

Install on macOS or Windows

  • macOS: extract the ZIP, open the TTF in Font Book, and use the install action. If validation reports an error, inspect it before relying on the font. Apple’s Font Book guide also explains duplicate handling.
  • Windows: extract the ZIP, right-click the TTF and choose Install. Depending on your setup, the action may be under Show more options or require permission. See Microsoft’s installation instructions.

Restart or reload the destination application if its font menu was already open. Installing a font in the operating system does not automatically make it available in every browser-based design service.

Pixel font not showing up after installation?

  1. Confirm you installed the .ttf, not just downloaded or previewed the ZIP.
  2. Check the PixelPlease family name in your system font manager.
  3. Close and reopen the design app; for Figma web, check the font installer requirement.
  4. If several exports are installed, select the intended variation rather than an older recipe.

To isolate the problem, try the same file in a simple desktop text app. If it appears there but not in your design tool, check that tool’s font access and refresh behavior before generating another file. A glyph showing as a box is a different problem from a missing family. This generator exports Basic Latin only; unsupported accented letters or other scripts need a different font or workflow.

Share the font, not just the document

Someone opening your editable design may need the same font file installed. Share the package only where the source license permits it, preserving required notices. A screenshot or outlined text is not a substitute for the font when collaborators need to edit words.

Read commercial use and redistribution before handing off files to a client. For a website, serve the font with CSS instead of asking every visitor to install it.
