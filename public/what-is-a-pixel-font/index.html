What is a pixel font, and is it the same as a bitmap font?

A pixel font describes a visual style: letters built around a visible grid. A bitmap font describes how glyphs are stored or rendered as images. A font can look pixelated while still being an installable outline font rather than a bitmap atlas.

Pixel art fonts, bitmap fonts and TTF files

  • Pixel-style outline font: letter shapes are geometric outlines with a grid-like appearance. You can type with it in compatible apps.
  • Bitmap font or atlas: glyphs are stored as pixel images, often with character positions and spacing data for a renderer.
  • Pixel text image: a finished word or sentence in a PNG; it is artwork, not an installable alphabet.

OpenType supports different kinds of glyph data; the filename or retro appearance alone does not tell you how a font will behave. “8-bit font” and “retro font” usually describe an aesthetic, not a required 8px size or an eight-bit font-file format. Godot’s font guide shows separate workflows for outline fonts and image-based fonts.

What pixelplease actually makes

pixelplease starts with an existing font and reconstructs sampled letter shapes as outlines. The download contains a generated TTF and notice material. It does not export a PNG text image, bitmap atlas or sprite-sheet mapping.

The output covers Basic Latin, not every character in the source. You can change text in another app after installing it, unlike a fixed image. See how TTF/OTF conversion works for the exact input and output limits.

Why a pixel-style font can still look blurry

The app or browser must rasterize an outline onto your screen. Fractional scaling, antialiasing and the chosen size can soften its edges even when the shapes themselves are square. An installable font does not guarantee identical rendering on every operating system.

A bitmap made for an 8-pixel grid might stay crisp at 16 or 24 pixels with suitable scaling, but that is not a universal size rule for every generated TTF. Diagnose the format and renderer first; use the rendering checklist rather than changing random font settings.

Choose the output your project needs

For editable poster text or a Figma mockup, an installable font is useful. For a website, use a licensed font file with CSS. For a game that requires a specific atlas format, choose a bitmap-font workflow or an additional compatible conversion tool.

Start from the destination: Figma, a website or a game. That prevents building a font package when what you really need is one finished image.
